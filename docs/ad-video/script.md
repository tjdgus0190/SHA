### CTA 문구 (확정 필요)
- 영상 기본값: 버튼 **"지금 만나보기"**, 링크 줄 **"링크는 프로필에서"**(9:16) / **"링크는 설명란에서"**(16:9).
- 요청안은 "지금 체험"이었지만, 랜딩페이지(`site/index.html`)에 체험판/무료 체험 언급이 없고 가격도 미정이라 체험이 존재한다고 단정하지 않았다. 체험판이 확정되면 재렌더 한 줄로 바꾼다:
  `node render/render.js --ar 9x16 --cta "지금 체험하기" --url "<랜딩 URL>"`
- 랜딩 URL은 아직 없음(Gumroad 플레이스홀더 상태) → 영상에 임의 URL을 넣지 않았다.

영상 파일에는 내레이션이 **없다**(효과음만). 위 문장은 TTS/성우 녹음용 초안이며 컷 길이에 맞춰 각 2초 이내.

## 16:9 변형 메모
- 같은 타임라인·같은 자막. 레이아웃만 다름: 자막은 왼쪽 열(좌측 정렬, x 100~840), 앱 목업은 오른쪽(x 880~1840).
- 유튜브 프리롤/트위터(X)/랜딩 히어로 영상용. 첫 5초 안에 문제(왔다갔다)와 팝업 등장(5.1s)이 모두 나온다 — 건너뛰기 버튼이 뜨는 5초 지점 직후 팝업이 등장한다.
- 링크 줄 기본값이 "링크는 설명란에서"로 바뀐다.

## 사실 확인 근거 (광고에 쓴 기능)
| 영상 속 표현 | 근거 |
|---|---|
| 커서 바로 옆(오른쪽 아래 +16px)에 팝업 | `app/main.js` `positionOverlayAtCursor()` |
| 포커스를 뺏지 않음 | `main.js` `overlayWin.showInactive()` |
| 트리거 = 중클릭(기본) | `app/config.js` `activationTrigger: { type: "mouse", code: 3 }` (F11도 기본 단축키) |
| L* 고정, 색조/채도만 이동하는 필드 | `app/overlay.js` `renderField()` + `colorMath.js` `labFieldPixel` |
| 명도 바 = 그 색을 유지하는 L* 구간만 | `overlay.js` `renderLightnessTrackGradient()` / `findLightnessRangeForChroma` |
| 고른 색이 히스토리에 모임(최대 8, 최신이 앞), 클릭으로 재적용 | `main.js` `pushHistory`, `HISTORY_MAX = 8`, `overlay.js` `renderHistory()` |
| Photoshop에서 바꾼 색(스포이드/패널)도 기준색·히스토리가 됨 | `main.js` `applyIncomingColor` → `setBaseFromRgb` + `pushHistory` |
| 꽃잎 3장이 모두 L* 68 | 영상 속 색을 `colorMath.labToRgb(68, a, b)`로 생성. 흑백 컷은 각 색의 L*로 만든 회색 |
