# SHA Paint 15초 광고 스토리보드 (컷별 구도)

기준 화면: 9:16, 1080x1920. 좌표는 px(세로 기준). 검증용 프레임 캡처는 `frames/` 폴더.

```

       │ │툴│  종이 캔버스  │패널│ │    툴바 / 종이(꽃 선화) / 색상·레이어 패널
y 1540 │ └──────────────────────┘ │

y 1600 │  (비움: 릴스/쇼츠 하단 UI 영역) │

```
- 팝업: 실제 크기 300x340을 1.5배(450x510)로 표시. 펜 끝(앱 좌표 150,150) 기준 +24px(=16px×1.5) 오른쪽 아래에 뜬다 — 실제 앱 배치 규칙과 같다.
- 하단 1600~1920은 플랫폼 UI(캡션/버튼)에 가려지는 영역이라 의도적으로 비웠다. 오른쪽 아이콘 열(x>960, 하단 절반)에도 중요한 요소 없음.
- 색: 배경 #1c1a1f, 본문 #f2ede4, 강조 금색 #e8a33d (랜딩페이지 토큰과 동일). 폰트: Noto Sans KR(본문), Noto Serif Bold(워드마크).

## 컷 1 — 0.0–2.6s "또 왔다갔다?"
- 구도: 앱 목업 전체 샷. 펜(측면 버튼 달린 스타일러스 일러스트, 28° 기울기)이 꽃 위 → 오른쪽 위 SV 사각형으로 크게 이동.
- 동작: 패널 클릭 시 SV 사각형에 금색 테두리 플래시 + 전경색 스와치 변경(진한 빨강). 캔버스 왼쪽 아래에 빨간 테스트 칠. 다시 색상 바 클릭(연분홍).
- 효과: 펜이 이동한 경로를 금색 점선으로 누적 → "왕복 거리"가 화면에 쌓여 보인다. 펜이 누른 구간(칠/지우개)은 점선에서 제외.
- 프레임 확인: `frames/mp4-9x16-1s.png`

## 컷 2 — 2.6–5.0s "칠했다 지웠다 / 이제 그만"
- 구도: 동일. 캔버스 오른쪽 아래에 연분홍 테스트 칠.
- 동작: 툴바 지우개 아이콘 활성(브러시 커서가 점선 원으로 커짐) → 두 테스트 칠을 문질러 지움 → 다시 패널에서 기준색(연어색, L* 68) 선택 → 펜이 캔버스 왼쪽 위로.
- 효과: 4.75~5.1s 점선 궤적 페이드아웃 (문제 파트 종료 신호).

## 컷 3 — 5.0–6.6s "펜 옆에 / 바로 팔레트"
- 구도: 펜 끝이 캔버스 왼쪽 위. 5.1s 펜 끝 금색 리플 + "중클릭" 알약 칩(펜 왼쪽 아래).
- 동작: 5.16s 팝업이 펜 끝 오른쪽 아래에서 90%→100% 스케일+페이드 인(0.16s).
- 팝업 내용(실제 UI 재현): 상단 전체 색역 아이콘 / L* 68 필드(비정형 색역 모양 그대로) + 흰 원 커서 / 명도 바(그 색을 유지하는 L* 구간만 그라데이션) / 현재·이전 스와치 + 히스토리 5칸.
- 프레임 확인: `frames/mp4-16x9-5s.png`(16:9), 9:16은 5.6s 스틸로 확인함.

## 컷 4 — 6.6–10.4s "같은 명도, / 어울리는 색만"
- 반복 3회, 회당 1.27s:
  1. (+0.00) 팝업 열림(2·3회차는 펜 끝 리플+팝)
  2. (+0.25~0.55) 펜이 필드 커서를 잡고 드래그 → 커서·현재 스와치·명도 바 실시간 변화
  3. (+0.56) 확정(틱) → 오른쪽 패널 전경색도 같은 색으로
  4. (+0.60) 팝업 닫힘(리플) → 펜이 꽃잎으로 → (+0.75~1.12) 지그재그로 꽃잎 채색
- 색 순서: 핑크(h0 C42) → 피치(h60 C44) → 라벤더(h300 C34), 모두 L* 68.
- 히스토리: 다시 열 때마다 방금 고른 색이 맨 앞에 추가되어 있다(실제 앱은 확정 후 COM 갱신으로 반영).
- 프레임 확인: `frames/mp4-9x16-10s.png` (꽃잎 3장 채색 완료, 펜이 라벤더 칠 마무리)

## 컷 5 — 10.4–11.6s "흑백으로 봐도 / 밝기 그대로"
- 구도: 팝업 없음, 꽃 전체가 보이는 앱 샷.
- 동작: 0.3s 동안 캔버스(종이·선화·꽃잎·가운데)가 L* 기준 흑백으로 전환 → 0.6s 유지 → 컬러 복귀.
- 포인트: 세 꽃잎이 정확히 같은 회색(#a6a6a6 근처)으로 보인다. 보조 자막 "칠한 꽃잎 3장 모두 L* 68".

## 컷 6 — 11.6–13.4s "고른 색은 / 여기 모인다"
- 동작: 팝업 재오픈 → 히스토리 줄에 금색 둥근 링(맥동) → 펜이 세 번째 칸(핑크) 탭, 칸에 금색 하이라이트 → 현재 스와치가 핑크로 → 팝업 닫힘 → 오른쪽 아래 꽃잎을 핑크로 칠함.
- 히스토리 상태(최신이 앞, 8칸): 라벤더, 피치, 핑크, 연어(기준색), 연분홍, 빨강, 갈색, 살구 — 컷 1~2에서 패널로 고른 색도 히스토리에 들어가 있다(실제 앱 동작).
- 탭 이후 히스토리 순서 변화는 보여주지 않는다(바로 닫힘) — 커밋된 v8.7과 개발 중 코드의 중복 처리 방식이 달라서 어느 쪽도 단정하지 않기 위함.
